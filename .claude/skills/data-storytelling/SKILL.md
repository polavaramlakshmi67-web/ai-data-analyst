# Data Storytelling

Sequence findings into a narrative arc that builds toward a conclusion.

## When to use this skill
Use this whenever a subagent or the orchestrator needs to: sequence findings into a narrative arc that builds toward a conclusion.

## Procedure
- Order findings from context -> tension (the problem found) -> resolution (the recommendation).
- Use one visual per key point rather than dumping all charts at once.
- End with a clear, specific call to action.
