# Executive Summary Format

Write a short, non-technical summary of an analysis for decision-makers.

## When to use this skill
Use this whenever a subagent or the orchestrator needs to: write a short, non-technical summary of an analysis for decision-makers.

## Procedure
- Lead with the finding and the recommended action, not the methodology.
- Keep it to 3-5 bullets; push detail to an appendix if needed.
- State the confidence level and key caveat in one line each.
