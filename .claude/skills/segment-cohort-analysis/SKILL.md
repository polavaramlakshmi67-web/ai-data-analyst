# Segment Cohort Analysis

Break a dataset into meaningful cohorts/segments and compare metrics across them.

## When to use this skill
Use this whenever a subagent or the orchestrator needs to: break a dataset into meaningful cohorts/segments and compare metrics across them.

## Procedure
- Choose segment boundaries that are meaningful to the business question, not arbitrary quantiles.
- Report sample size per segment — flag segments too small to trust.
- Highlight the segments that diverge most from the overall average.
