# Data Quality Audit Checklist

Run a systematic data quality audit before a dataset is used for decisions.

## When to use this skill
Use this whenever a subagent or the orchestrator needs to: run a systematic data quality audit before a dataset is used for decisions.

## Procedure
- Check completeness, consistency, timeliness, and accuracy dimensions explicitly.
- Score each dimension and give an overall pass/fail with specific failing examples.
- Re-run the audit whenever the upstream pipeline changes.
