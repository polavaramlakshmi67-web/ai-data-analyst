# Citation And Sourcing

Track and cite the data sources and methods behind every claim in a report.

## When to use this skill
Use this whenever a subagent or the orchestrator needs to: track and cite the data sources and methods behind every claim in a report.

## Procedure
- Record the exact source table/query/API endpoint behind each figure quoted.
- Note the data's as-of date/freshness in the report.
- Flag any figure derived from a sample vs. the full population.
